# 依赖说明

## 1 授权范围

项目自身源代码采用 MIT，各依赖保留自己的许可证，安装包中的许可证文件应随各包查看

以下直接依赖信息来自本次锁定安装的 package.json，版本与 package-lock.json 对应，清单不替代完整的传递依赖审查

## 2 程序依赖

前端依赖在构建时编入网页资源，不再作为网关的 Node.js 运行依赖重复安装；实际编入网页的组件及其许可文本收录在 `THIRD_PARTY_NOTICES.txt`，以下清单保留直接依赖信息
